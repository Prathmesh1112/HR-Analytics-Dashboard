📊 HR Analytics Dashboard | Power BI

 Project Overview:-

The HR Analytics Dashboard is an interactive Power BI project designed to analyze employee data and provide actionable insights into workforce performance, attrition, demographics, and job satisfaction. It enables HR teams to monitor key metrics, identify trends, and make data-driven decisions.

🚀 Features :- 

📈 Total Employees KPI

👥 Active Employees Analysis

⭐ Average Performance Score

💰 Sum of Daily Rate

🎂 Average Employee Age

💼 Average Experience

📊 Attrition Analysis by Department

💵 Monthly Income Distribution

😊 Employee Satisfaction by Job Role

👨‍💼 Gender-wise Employee Count

🎯 Department-wise Employee Distribution

📅 Years at Company Analysis

🎛️ Interactive Department Slicer




🛠️ Tools & Technologies :- 

1) Microsoft Power BI

2) Power Query

3) DAX (Data Analysis Expressions)

4) Data Modeling

5) Data Visualization

   


📊 Key Insights :-


1) Workforce distribution across departments

2) Employee attrition trends

3) Salary and income analysis

4) Job satisfaction comparison

5) Gender diversity analysis

6) Employee age distribution

7) Experience and tenure insights

   


📈 Dashboard KPIs :-


1) Total Employees

2) Active Employees

3) Average Performance

4) Sum of Daily Rate

5) Average Age

6) Average Experience

   



🎯 Business Objective :- 

The primary objective of this dashboard is to help HR professionals monitor employee performance, understand workforce demographics, identify attrition patterns, and support strategic decision-making using interactive visual analytics.
